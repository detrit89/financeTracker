# Finance Tracker

Учебное full-stack приложение для учёта личных доходов и расходов. Позволяет добавлять операции, следить за балансом и находить нужные записи в истории.

## Статус проекта

Проект находится в активной разработке. Текущая тестовая версия ориентирована на десктоп.

**Адаптивная версия для телефонов и планшетов появится чуть позже.** Пока интерфейс рекомендуется открывать на компьютере.

Следующий этап — размещение фронтенда и бэкенда на серверах. Ссылки на работающую демоверсию и API будут добавлены после развёртывания.

## Возможности

- **Overview** — баланс, общие доходы и расходы, пять последних добавленных операций.
- **Transactions** — история операций, поиск по описанию и типу, фильтрация доходов и расходов.
- Добавление операций с описанием, суммой, типом и датой.
- Редактирование описания, суммы и даты операции.
- Удаление операций.
- Очистка формы после успешного добавления.
- Хранение данных в SQLite.
- **Settings** — страница-заготовка для будущих настроек.

## Локальный запуск

### Требования

- Node.js 22.12+ или совместимая с Vite версия.
- npm.
- Bun.
- Современный браузер с поддержкой `Array.prototype.toSorted`.

### Установка зависимостей

Из корня проекта:

```sh
npm ci
cd front
npm ci
cd ../backend
bun install
```

Установка в корне нужна, поскольку Tailwind CSS и его Vite-плагин сейчас объявлены в корневом `package.json`.

### Бэкенд

В первом терминале, из корня проекта:

```sh
cd backend/src
mkdir -p data
bun server.js
```

По умолчанию API доступен на `http://localhost:3000`.

В текущей реализации путь `data/finance.sqlite` считается относительно рабочей папки. Запуск из `backend/src` использует `backend/src/data/finance.sqlite`. При первом запуске таблица создаётся автоматически.

### Фронтенд

Во втором терминале, из корня проекта:

```sh
cd front
npm run dev -- --port 5173 --strictPort
```

Откройте `http://localhost:5173`.

Сейчас фронтенд обращается к `http://localhost:3000/api/transactions`, а CORS бэкенда разрешает `http://localhost:5173`.

## Команды фронтенда

Выполняются из папки `front`:

```sh
npm run dev          # режим разработки
npm run lint         # проверка ESLint
npm run build        # сборка в dist
npm run preview      # локальный просмотр сборки
```

Для работы API через preview нужно отдельно разрешить его origin в CORS; стандартный адрес preview — `http://localhost:4173`.

## API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | `/api/transactions` | Получить все операции |
| GET | `/api/transactions/:id` | Получить одну операцию |
| POST | `/api/transactions` | Добавить операцию |
| PATCH | `/api/transactions/:id` | Изменить операцию |
| DELETE | `/api/transactions/:id` | Удалить операцию |

Пример тела POST-запроса с заголовком `Content-Type: application/json`:

```json
{
  "type": "expense",
  "amount": 25000,
  "description": "покупка машины",
  "transaction_date": "2026-10-29"
}
```

- `type` — `income` или `expense`.
- `amount` — положительное целое число. Дробные суммы пока не поддерживаются.
- `description` — непустое описание.
- `transaction_date` — дата операции; интерфейс передаёт её в формате `YYYY-MM-DD`.

PATCH принимает изменяемые поля. Успешное создание возвращает статус 201, изменение и удаление — 200, тело ответа — `{"success":true}`.

## Размещение на серверах

Фронтенд и бэкенд планируется разместить отдельно. Конкретные адреса будут добавлены после запуска.

Для развёртывания потребуется:

1. Заменить локальный адрес API в `front/src/api/transaction.js` на адрес размещённого бэкенда либо настроить адрес через переменную окружения с соответствующим изменением кода.
2. Разрешить адрес фронтенда в CORS бэкенда.
3. Собрать фронтенд и опубликовать содержимое `front/dist`.
4. Настроить возврат `index.html` для клиентских маршрутов `/transactions` и `/settings`.
5. Запустить API через Bun с доступом к постоянному хранилищу SQLite. База должна сохраняться между перезапусками и обновлениями сервера.
6. Проверить загрузку изображений и операции создания, редактирования и удаления на опубликованной версии.
